# Codebreaker

A 2D top-down stealth heist game developed for **UTSA RowdyHacks XII: Hack & Heist (2026)** using Unity and C#.

## Overview

Codebreaker is a stealth-based game where players take on the role of a thief attempting to break into a bank vault. Players must explore the environment, collect security codes, avoid laser security systems, and unlock the vault.
## Features

* Top-down 2D player movement
* Vault combination system
* Interactive computers that reveal code fragments
* Timed code retrieval mechanic
* Laser security obstacles
* Countdown timer
* Interactive vault keypad

## Built With

* Unity 6
* C#
* Unity 2D Physics
* Unity Input System
* Cinemachine
* GitHub

## How to Play

1. Download the game from the Releases section.
2. Extract the ZIP file.
3. Run the game executable.
4. Explore the bank and locate the computers.
5. Retrieve all code fragments.
6. Avoid security lasers and unlock the vault before time runs out.
